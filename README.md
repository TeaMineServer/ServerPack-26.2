# TeaMine 26.2

Сборка для сервера **TeaMine** на Minecraft 26.2 (Fabric).

Сайт: [teamine.onl](https://teamine.onl)

## Установка

1. Скачайте `TeaMine Installer.exe` из [Releases](https://github.com/TeaMineServer/ServerPack-26.2/releases)
2. Запустите установщик
3. Укажите папку `.minecraft`
4. Готово
